
Modern PostgreSQL: IDENTITY

Recommended over SERIAL.

CREATE TABLE users (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name TEXT
);

Insert:

INSERT INTO users(name)
VALUES ('Rahul');

Result:

id	name
1	Rahul

=================================================

ALWAYS vs BY DEFAULT

GENERATED ALWAYS AS IDENTITY

Database generates value.

This fails:

INSERT INTO users(id, name)
VALUES (100, 'Rahul');

Error.

GENERATED BY DEFAULT AS IDENTITY

Database generates value unless provided.

CREATE TABLE users (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT
);

This works:

INSERT INTO users(id, name)
VALUES (100, 'Rahul');
