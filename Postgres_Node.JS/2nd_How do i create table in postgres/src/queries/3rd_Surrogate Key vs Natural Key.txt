
Surrogate Key vs Natural Key
Natural Key

Data itself uniquely identifies rows.

Example:

Passport Number.

passport_number VARCHAR(20) PRIMARY KEY


Advantages:

Meaningful
Already exists

Disadvantages:

May change
Large size
Business rules can change

Surrogate Key

Artificial key generated by database.

Example:

id INTEGER PRIMARY KEY

Advantages:

Stable
Small
Faster joins
Recommended in most applications

Disadvantages:

No business meaning
