# Sabse Pehle Problem Samjho

Normal HTML me:

```html
<input type="text" />
```

Question:

```text
Input ke andar jo value user type karega,
wo kahan store hogi?
```

Answer:

```text
Browser DOM ke andar
```

Browser khud value manage kar raha hai.

Example:

```html
<input id="name" />
```

User type karta hai:

```text
Rahul
```

Browser internally:

```html
<input value="Rahul" />
```

maintain karta hai.

React ka state involve nahi hai.

---

# Controlled Component Kya Hai?

Definition:

```text
A Controlled Component is a form element whose value is controlled by React State.
```

Simple Hindi:

```text
Browser nahi,
React state input ko control karegi.
```

---

# Uncontrolled Input

```jsx
function App() {
  return <input type="text" />;
}
```

Yahan:

```text
Input Value Owner
      ↓
Browser DOM
```

---

# Controlled Input

```jsx
function App() {
  const [name, setName] = useState("");

  return (
    <input
      value={name}
      onChange={(e) =>
        setName(e.target.value)
      }
    />
  );
}
```

Yahan:

```text
Input Value Owner
      ↓
React State
```

# Why Use Controlled Components?

## 1. Validation

Example:

```jsx
<input
  value={name}
  onChange={(e) => {
    if (
      e.target.value.length <= 10
    ) {
      setName(
        e.target.value
      );
    }
  }}
/>
```

User:

```text
abcdefghijklmnop
```

type kare.

React allow nahi karega.

---

## 2. Real-time Error Checking

```jsx
const [email, setEmail] =
useState("");

const [error, setError] =
useState("");
```

Every keystroke pe:

```js
validateEmail()
```

run kar sakte ho.

---

## 3. Formatting

Phone:

User:

```text
9876543210
```

React:

```text
98765-43210
```

display kar sakta hai.

---

## 4. Reset Forms

```jsx
setName("");
setEmail("");
```

Pure form reset.

# Multiple Inputs

Real Forms:

```jsx
const [form, setForm] =
useState({
  name: "",
  email: ""
});
```

---

Input:

```jsx
<input
  name="name"
  value={form.name}
  onChange={handleChange}
/>
```

---

Handler:

```jsx
const handleChange = (
  e
) => {
  setForm({
    ...form,

    [e.target.name]:
      e.target.value
  });
};
```

---

Flow:

```text
name input
      ↓
form.name update

email input
      ↓
form.email update
```

# Common Interview Question

## What Happens If Value Is Given But onChange Is Missing?

```jsx
<input value={name} />
```

React warning:

```text
You provided a value prop
without an onChange handler
```

Why?

Because:

```text
Value controlled hai
but update mechanism nahi hai
```

Input read-only ban jayega.

# Controlled vs Uncontrolled

| Controlled           | Uncontrolled    |
| -------------------- | --------------- |
| React owns value     | DOM owns value  |
| useState used        | Ref used        |
| Easy validation      | Hard validation |
| Easy reset           | Hard reset      |
| More renders         | Less renders    |
| Most common in React | Less common     |

# Uncontrolled Example

```jsx
function App() {
  const inputRef =
    useRef(null);

  const handleClick = () => {
    console.log(
      inputRef.current.value
    );
  };

  return (
    <>
      <input
        ref={inputRef}
      />

      <button
        onClick={
          handleClick
        }
      >
        Submit
      </button>
    </>
  );
}
```

Yahan:

```text
Input Value Owner
      ↓
DOM
```

# Interview Definition

```text
A Controlled Component is a form element whose value is controlled by React state rather than the DOM.

The current value is stored in state and updated through event handlers such as onChange. React becomes the single source of truth for the form data.
```

Sabse important line yaad rakho:

```text
Controlled Component ka core idea hai:

"Single Source of Truth"

Aur wo source React State hoti hai,
browser DOM nahi.
```

Is topic ke baad logically next concept hai:



**Uncontrolled Components**, **refs**, aur phir **React Hook Form internally controlled aur uncontrolled approach ko kaise combine karta hai**. Ye interview aur real projects dono me bahut important hai.
